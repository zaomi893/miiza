Verified boot recomputes ro.boot.vbmeta.digest and .size from the real AVB chain on-device. Boot-state normalizes the lock-state/warranty/debuggable props and, where the kernel exposes it, the raw /proc/cmdline + /proc/bootconfig boot-state to match — only ever changing a prop that already exists, and skipping procfs if the kernel has no nomount knobs. Kernel uname keeps the running kernel's base and swaps the tail + build date so uname matches the ROM; blank keeps the current values, or paste them from a stock device. Apply now runs it immediately.
